# Трекинг развития Word/OpenXML

## Цель
Сделать компактный fluent API для чтения и записи данных в docx, сохраняя текущую философию проекта:
- короткие точки входа (`Word.*`)
- chain-стиль конфигурации
- явные операции сохранения

## Что реализовано в текущем проходе
- Добавлен fluent-редактор существующего документа: `Word.Open(...)` -> `WordDocument`
- Добавлен fluent-конструктор нового документа: `Word.Create()` -> `WordBuilder`
- Добавлено чтение полей напрямую из `Word`: `Word.Fields` / `Word.EnumFields()`
- Исправлена опечатка имени extension-класса `ExtensionsOpenXmlPackage`
- Исправлены явные ошибки/опечатки в `README.md`

## Новый API (минимальный компактный)
### Редактирование существующего документа
```csharp
Word.Open("input.docx")
   .Field("CustomerName", customer.Name)
   .Field("CreatedAt", () => DateTime.Now.ToString("O"))
   .RemoveUnprocessedFields()
   .ReplaceFieldsWithValues()
   .SaveTo("output.docx");
```

### Создание нового документа
```csharp
Word.Create()
   .Paragraph("Отчет")
   .Paragraph("Сформировано автоматически", p => p.AlignRight().Italic())
   .Table(
       new[] { "ID", "Наименование", "Цена" },
       new[] { "1", "Товар 1", "100" }
   )
   .SaveTo("report.docx");
```

## Ближайшие варианты расширения (реализуемо следующим шагом)
- [ ] `Word.Open(...).Read(tag)` и `ReadAll()` для прямого получения значений полей без ручной фильтрации
